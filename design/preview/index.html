Closest pair in a sorted shelf

A warehouse shelf holds boxes in increasing order of weight. Given the list weights and a number limit, return the positions of the two boxes whose combined weight is as close as possible to limit without going over.

Positions start at 0. If no pair fits, return an empty list. Exactly one best pair exists in every test.

Inputweights = [2, 5, 8, 12, 17], limit = 21
Output[1, 3]
Because5 + 12 = 17 is beaten by 2 + 17 = 19, and 8 + 12 = 20 beats both.
Inputweights = [9, 14], limit = 10
Output[]

2 ≤ weights.length ≤ 100 000. Aim for a single pass.

Open only what you need. Each level tells you how much of this solve will count.

Nudge Counts in full

The list is already sorted. What does that let you say about every pair that includes the heaviest box?

Approach Counts 70%

Keep one marker at each end. When the sum is over the limit, only one of the two markers can sensibly move.

Almost the answer Counts 40%

Move the right marker left when the sum is too big; otherwise record the pair if it is the best so far and move the left marker right.

class Solution:
def closest_pair(self, weights, limit):
# one marker at each end of the sorted shelf
lo, hi = 0, len(weights) - 1
best, best_sum = [], -1
while lo < hi:
total = weights[lo] + weights[hi]
if total > limit:
hi -= 1
else:
if total > best_sum:
best, best_sum = [lo, hi], total
lo += 1
return best
